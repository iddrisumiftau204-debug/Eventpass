\section{Overview}
EventPass allows organizers to create events and manage attendee admissions.
\section{Workflow}
\begin{enumerate}
  \item Register/login
  \item Create event
  \item Register attendees
  \item Capture ticket code or QR
  \item Check in people at the venue
\end{enumerate}
\section{Notes}
The check-in screen accepts typed codes and QR-based scan input. Duplicate check-ins are rejected.
